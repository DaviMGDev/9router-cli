# 9router-cli

Fast, scriptable Python CLI client for managing the [9Router](https://github.com/decolua/9router) local AI gateway.

## Features
- **Combos management**: Create, inspect, update, and delete model fallback combos safely.
- **Provider & Model discovery**: Query active providers and discover models.
- **Client API keys**: Issue and revoke gateway keys for local coding agents.
- **Settings & Tools**: Inspect status of CLI integrations and Cloudflare tunnel.
- **Raw JSON mode**: All commands support `--json` for shell scripting.
